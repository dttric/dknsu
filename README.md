# dkn.su — Hub, Blog & Dashboard

Официальный сайт-хаб и блог для группы **dkn** на домене `dkn.su`.

Вдохновлен минималистичной эстетикой `dttric.github.io`:
- Статичный лаконичный заголовок `dkn.su`.
- **Информационный дашборд**:
  - **Издание // Новости**: лента с первыми 3 постами из блога, фильтрами по рубрикам (`все`, `релизы`, `статьи`, `объявления`) и ссылкой на полный архив.
  - **API**: блок с плейсхолдером `to be added...`.
  - **Статус-бар**: онлайн-индикатор, пинг и живые часы.
- **Блог на Jekyll**:
  - Каталог `_posts/` с Markdown-постами.
  - Шаблоны `_layouts/default.html` и `_layouts/post.html`.
  - Страница полного архива публикаций `blog.html` (`/blog`).
  - Конфигурация `_config.yml`.
- **Конфигурация Vercel**:
  - Файл `vercel.json` с поддержкой красивых URL без расширения `.html` (`cleanUrls: true`), заголовками безопасности и автоматической сборкой.
- **Сайдбар**:
  - `social`: Telegram, GitHub, Steam, Email.
  - `projects`: `// все будет, но не сейчас`.
  - `services`: только `publications` (ссылка на блог).
- **Страницы ошибок**: стилизованные `204.html` (`/204`) и `404.html` (`/404`) с темным фоном, координатной сеткой и радиальной виньеткой.
- **Мобильная версия**: на мобильных экранах (`< 992px`) дашборд скрывается, отображается чистый и быстрый мобильный хаб со ссылками.

## Структура файлов

```text
dknsu/
├── _config.yml         # Конфигурация Jekyll
├── _layouts/
│   ├── default.html    # Базовый шаблон блога с шапкой и футером
│   └── post.html       # Шаблон отдельного поста
├── _posts/             # Посты блога (Markdown)
│   ├── 2026-06-10-welcome-to-dkn.md
│   ├── 2026-07-02-repositories-and-branches.md
│   ├── 2026-08-14-lightweight-web-services.md
│   └── 2026-09-20-infrastructure-update.md
├── _site/              # Скомпилированный сайт, готовый к деплою
├── blog.html           # Страница всех публикаций (архив блога)
├── blog.css            # Стили блога и постов
├── index.html          # Главная страница (сайдбар и дашборд)
├── style.css           # Стили главной страницы (сетка, стеклянные карточки, адаптив)
├── app.js              # Логика новостей, фильтрации, живых часов и пинга
├── feed.json           # JSON-файл данных (первые 3 поста для дашборда)
├── 204.html            # Страница 204 No Content
├── 404.html            # Страница 404 Not Found
├── error.css           # Стили страниц ошибок (типографика, виньетка, сетка)
├── vercel.json         # Конфигурация Vercel (cleanUrls, rewrites, заголовки)
├── build.py            # Локальный компилятор Jekyll в _site/
├── Gemfile             # Зависимости Jekyll для Ruby/CI
├── CNAME               # Доменная привязка dkn.su
└── README.md           # Документация проекта
```

## Деплой на Vercel

1. Загрузите репозиторий на GitHub.
2. Подключите репозиторий в [Vercel](https://vercel.com).
3. `vercel.json` автоматически настроит:
   - Сборку через `python build.py` в папку `_site`.
   - Красивые ссылки без `.html`:
     - `https://dkn.su/blog` вместо `blog.html`
     - `https://dkn.su/204` вместо `204.html`
     - `https://dkn.su/blog/2026-09-20-infrastructure-update` вместо `.html`
   - Заголовки безопасности и кэширования статики.
